# SIGNELYA — Contrat de génération IA

Ce fichier doit être injecté dans tout agent chargé de produire un visuel, une vidéo, une publicité, un mockup, une interface ou un support SIGNELYA.

## Bloc système — identité non négociable

```text
BRAND: SIGNELYA
PARENT BRAND: JS-Innov.IA®
OFFICIAL TAGLINE: "Vos écrans prennent vie."

SIGNELYA visual identity is built around:
1) a dominant fluid S-shaped ribbon,
2) a secondary rounded digital-screen frame,
3) a small stream of square pixels entering/assembling from the left,
4) the official gradient cyan #00D9FF → electric blue #1778FF → violet #754BFF → magenta #F100FF,
5) a near-black premium background #03050A.

The look must be premium, precise, fluid, technological and professional. It must NOT become gaming, generic cyberpunk, rainbow, cluttered, cartoonish or excessively holographic.

SIGNELYA must always be spelled exactly: SIGNELYA.
If the tagline is used, it must always be written exactly in French: "Vos écrans prennent vie."

JS-Innov.IA® is the parent brand. NEVER redraw, regenerate, approximate, reinterpret or invent the JS-Innov.IA® logo. Use only the supplied official JS-Innov.IA® asset. If no official parent-brand asset is supplied to the image/video model, leave a clean reserved space and add the official logo during post-production.

Do not distort, rotate, replace or morph the SIGNELYA S-ribbon geometry in a final brand lockup.
For small icons, remove slogan and tiny text; preserve the S-ribbon + screen + pixel concept.
For giant LED / roadside displays, prioritize distance readability, high contrast and one key message per scene.
```

## Prompt visuel — modèle

```text
Create a premium SIGNELYA brand visual for [FORMAT / USE].
Subject / scene: [SCENE].
Primary message: [MESSAGE].
Audience: [AUDIENCE].
Viewing context: [MOBILE / WEB / 4x2m LED / SOCIAL / PRESENTATION].

Respect the SIGNELYA master DNA exactly:
- near-black #03050A environment,
- official cyan → electric blue → violet → magenta gradient,
- fluid S-ribbon as the hero symbol,
- subtle rounded screen-frame geometry,
- controlled square-pixel trail,
- premium lighting, clean negative space, strong readability,
- no generic cyberpunk clutter,
- no extra colors dominating the composition,
- no invented logos.

If exact typography cannot be guaranteed, generate the artwork without brand text and reserve a clean area for the official vector wordmark to be composited afterward.
```

## Prompt vidéo — modèle

```text
Create a SIGNELYA motion sequence for [FORMAT] lasting [DURATION].

Motion DNA:
1. a few cyan pixels appear,
2. pixels move toward a subtle digital screen frame,
3. a light trace draws the official S-ribbon,
4. the ribbon gains controlled blue/violet/magenta energy,
5. the scene stabilizes into a clean premium SIGNELYA composition,
6. wordmark and tagline are added only if exact supplied assets can be preserved.

Motion must feel fluid, precise and intentional.
No strobing, no violent white flashes, no permanent glitch, no cartoon bounce, no full 3D spin of the logo, no geometry morphing.

For giant LED / roadside use:
- one visual idea per shot,
- high contrast,
- avoid fine detail,
- keep logo readable immediately,
- do not overload the final frame.
```

## Négatif global

```text
Avoid: rainbow palette, green/orange/red dominance, generic hacker imagery, hooded silhouettes, binary-code backgrounds, excessive particles, multiple lens flares, illegible futuristic fonts, distorted wordmarks, fake client logos, fake JS-Innov.IA logos, busy dashboards, childish animation, casino/gaming look, cheap chrome, uncontrolled neon.
```

## Procédure de conformité

Avant export, l'agent doit vérifier :

- `SIGNELYA` exact.
- Slogan exact s'il apparaît.
- Gradient officiel.
- S-ruban + cadre écran + pixels préservés.
- Logo JS-Innov.IA® officiel uniquement.
- Lisibilité adaptée à la distance et au format.
- Aucun texte halluciné dans le logo.
- Aucun élément de marque inventé.
